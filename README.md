# NetBridge

**اشتراک اینترنت گوشی به سیستم — با لحاظ‌شدن VPN گوشی روی نتِ شیرشده.**

مثل PdaNet، اما رایگان، متن‌باز، و دلخواه شما.

---

## چرا NetBridge؟

روی گوشی VPN می‌زنید (هات‌اسپات یا USB را هم شیر می‌کنید)، اما در حالت عادی ترافیک PC از کنار VPN رد می‌شود و مستقیم به اینترنت می‌رود — یعنی نتِ شیرشده از تونلِ شما بیرون می‌زند.

به ابزارهای موجود نخوردم: یا **پولی** بودند، یا **دلخواه** نبودند، یا VPNِ خودم را روی نتِ شیرشده اعمال نمی‌کردند. برای همین NetBridge را ساختم.

## راه‌حل

NetBridge بین سیستم و گوشی یک **پل پروکسی** می‌سازد. چون خروجی پروکسی، ترافیک خودِ گوشی است، از VPN فعالِ روی گوشی عبور می‌کند → **نت شیرشده هم شامل VPN می‌شود.** بدون Root، بدون سرور، بدون تغییر VPN دلخواه شما.

```
مرورگر PC → System Proxy ویندوز → پروکسی گوشی → VPN گوشی → اینترنت
```

### دو نکته فنی که کار را راه می‌اندازند

**۱. تشخیص VPN.** اندروید فقط یک شبکه را active می‌کند؛ با روشن‌شدن USB tethering همان رابط تتر active می‌شود و بررسی ساده `activeNetwork` دیگر VPN را نمی‌بیند. اپ همه شبکه‌ها را می‌گردد و سه حالت متفاوت را از هم جدا می‌کند: «VPN روشن است»، «VPN روشن است ولی گوشی اینترنت ندارد» و «VPN خاموش است». هر کدام پیام و راهکار مخصوص خودش را دارد (`mobile/.../net/Interfaces.kt`).

**۲. مسیر خروجی پروکسی.** سوکت‌های خروجی به شبکه‌ای bind می‌شوند که تونل را حمل می‌کند، تا ترافیک سیستم واقعاً از VPN عبور کند و به مسیر پیش‌فرض تتر نرود (`Interfaces.preferredRoute()`). اگر VPN روشن باشد هرگز به WAN فیزیکی bind نمی‌شویم (بای‌پس تونل). اگر bind ممکن نبود، با احتیاط به مسیر پیش‌فرض برمی‌گردد تا هیچ درخواستی بی‌دلیل رد نشود.

## شروع سریع

### اندروید

**روش ۱ — ساخت در ابر (بدون نصب چیزی):**

ریپو را روی GitHub بسازید؛ workflow زیر خودکار APK می‌سازد و در **Actions → Artifacts** آپلود می‌کند:

- `.github/workflows/android.yml` → `NetBridge-debug` و `NetBridge-release`
- `.github/workflows/desktop.yml` → نصب‌کننده ویندوز
- `.github/workflows/test.yml` → تست‌ها

**روش ۲ — محلی:**

`mobile/` را در Android Studio باز کنید → **Build APK(s)**

### ویندوز

```bash
cd desktop
npm install
npm run dev
```

ساخت نصب‌کننده:

```bash
npm run dist
```

### اتصال

1. VPN دلخواه روی گوشی → روشن (حالت «همه برنامه‌ها»)
2. اپ NetBridge → دکمه اشتراک
3. یکی از دو راه:
   - **هات‌اسپات:** هات‌اسپات را روشن کنید، PC را وصل کنید → IP گوشی معمولاً `192.168.43.1`
   - **USB:** کابل را وصل کنید و در تنظیمات گوشی **«اشتراک اینترنت USB»** را روشن کنید → IP گوشی معمولاً `192.168.42.129`
4. اپ دسک‌تاپ روی PC → گوشی را پیدا کن → کد ۶ رقمی را وارد کن → اتصال
5. تمام. System Proxy ویندوز روشن است.

> **نکته مهم USB:** وصل‌کردن کابل به‌تنهایی اینترنت را شیر نمی‌کند. تا وقتی «اشتراک اینترنت USB» روی گوشی روشن نشود، PC هیچ راهی به پروکسی گوشی ندارد.

> **اگر ویندوز گفت اینترنت ندارد:** بعضی نسخه‌های ویندوز وقتی اتصال تتر را «متراکم» (metered) یا بدون تأیید اینترنت بدانند، پروکسی را نادیده می‌گیرند. در تنظیمات شبکه همان اتصال، گزینه «اتصال متراکم» را خاموش کنید.

## تست

```bash
npm test
```

شش مرحله: تایپ‌چک دسک‌تاپ، بیلد، و دو تست که **بدون گوشی و بدون Android Studio** اجرا می‌شوند:

- **smoke test** — کلاس واقعی `ProxyChain` را روی یک «گوشی قلابی» می‌راند و مسیر ترافیک، شمارنده بایت، تونل `CONNECT`، حالت‌های خطا (`502`/`503`) و ۲۰ اتصال همزمان را بررسی می‌کند.
- **contract test** — ۳۸ بررسی روی قرارداد Kotlin ↔ TypeScript، تا فیلدی که در یک طرف تغییر کرده و در طرف دیگر نه، گرفته شود.

برای ساخت `exe` و `apk` و تست واقعی روی گوشی → [docs/testing.md](docs/testing.md).

## عیب‌یابی سریع

| نشانه | معنا | کار |
|-------|------|-----|
| «اینترنت گوشی در دسترس نیست» | تونل VPN بدون شبکه زیرین | VPN را قطع کنید یا اتصال داده را بررسی کنید |
| «راه اتصال سیستم: بدون اتصال» | نه هات‌اسپات روشن است نه USB | یکی را روشن کنید |
| «VPN فعال نیست» | شیر کار می‌کند ولی از تونل رد نمی‌شود | اپ VPN را در حالت «همه برنامه‌ها» روشن کنید |
| لیست «کلاینت‌های متصل» خالی است | درخواست‌ها به گوشی نمی‌رسند | آدرس گوشی و فایروال ویندوز را بررسی کنید |

جدول کامل → [docs/deployment.md](docs/deployment.md)

## محدودیت‌ها

- پوشش System Proxy: مرورگرها و بیشتر برنامه‌های ویندوز — مثل PdaNet
- ترافیک خام UDP برخی بازی‌ها: پشتیبانی نمی‌شود (TUN سیستم‌سطح در نسخه بعدی)
- اپ VPN را در حالت «همه برنامه‌ها» نگه دارید
